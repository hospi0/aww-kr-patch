# 영문/로마자 번역표 보관본 (2026-07-26, 세션15)

세션15에 사용자 결정으로 **유닛타입·이동타입·미션명(작전명)·시나리오 제목·유닛 이름**을
전부 한글화하기로 했다. 그 직전의 **영문/로마자 상태**를 그대로 보관한 것이다.

## 왜 보관하나
이 영문표들은 「예산이 없어서」 만든 게 아니라 대부분 **예산을 아끼려고** 택한 것이었다
(라틴 글리프는 폰트에 이미 있어 신규 음절 0). 세션15의 천장 실측으로 예산이 확보돼
한글로 되돌리지만, 아래 경우에 다시 필요할 수 있어 남긴다.

- 특정 폰트가 예산 초과로 밝혀져 일부를 라틴으로 되돌릴 때
- **소형 8×8 폰트**처럼 구조적으로 한글이 불가능한 곳(240글리프 중 53칸이 유닛아이콘
  그래픽이라 회수 불가)에 계속 써야 할 때
- 고유명사를 라틴으로 두는 편이 낫다고 판단이 바뀔 때

## 보관 파일

## 되돌리는 법
해당 파일을 `tools/` 로 복사하면 된다. 단 **빌더가 그 사이 바뀌었을 수 있으니**
번역표(딕셔너리)만 옮기는 편이 안전하다.
