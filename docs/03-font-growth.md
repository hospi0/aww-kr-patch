# 폰트 재배치·확장 실험 (실기 통과)

작성 2026-07-20 / 세션 1. 판정 대상 = 초기조사 §6 "글리프 예산".

## 결론

**폰트 파일은 옮길 수도 있고 키울 수도 있다.** 로더가 ISO9660 디렉터리의
extent(위치)와 size(크기)를 둘 다 정직하게 읽는다.
→ 글리프 예산은 하드 제약이 아니다. 어휘 제한이나 품질 절충이 필요 없다.

## 배경 — 왜 이 실험이 필요했나

`tools/budget.py` / `tools/demand.py` 측정:

| 폰트 | 전체 | 한글 가용(가나+한자 폐기) |
|---|---:|---:|
| ASC16CG (전역 본문) | 825 | 733 |
| ASCMSCG | 830 | 737 |
| ASCGSCG (타이틀·전사) | 594 | **520** |
| ASCIMCG | 697 | 615 |
| SAKUCG | 1017 | 1017 |

수요는 실제 원문을 번역한 표본(음절 1,208 / 고유 263종)으로 Heaps' law 적합:
**U = 5.21·N^0.560** → 4천음절 543종 / 1만 907종 / 4만 1,973종.

ASCGSCG 풀은 일본어 5,721자라 한국어 5~6천 음절 → **620~680종 필요 vs 공급 520**.
ASC16CG는 인게임 본문 전체를 감당하므로 훨씬 크게 부족.
⚠️표본이 1,208토큰이라 대규모 외삽은 불확실하나, **부족하다는 방향은 뒤집히지 않는다.**

## 실험 1 — 재배치 가능한가

새턴 게임은 ISO 디렉터리를 무시하고 LBA를 하드코딩하는 경우가 흔하다
(`references/platforms/saturn.md` §5). 그래서 먼저 이것부터 갈랐다.

**설계 (이분 실험 — 변수 하나)**
- ASCGSCG를 lba 3434 → **259296**(트랙 끝 여유)으로 **크기 그대로** 복사
- ★**옮긴 사본에만 한글 주입, 원래 자리는 원본 일본어 그대로 유지**
- 루트 디렉터리 레코드의 extent만 LE·BE 갱신

**판독** — 원본 슬롯이 兵器図鑑司令蔵抗… 한자라 한글과 확연히 다르다.
한글이면 새 사본을 읽은 것, 한자면 옛 자리를 읽은 것.

**결과 ✅ 한글 표시 = 로더가 ISO 디렉터리를 읽는다.**

## 실험 2 — 확장 가능한가

실험 1 상태에서 **파일 크기 하나만** 더 바꿨다.

- ASCGSCG **594 → 850 글리프** (76,032 → 108,800 B), 54섹터
- ★**기존 594글리프는 원본 한자 그대로**, 한글 15자는 **신규 인덱스 594~608에만**
- 루트 디렉터리의 **extent + size 둘 다** LE·BE 갱신

**결과 ✅ 한글 표시 = 늘어난 영역까지 적재·렌더된다.**

## 재현 방법

```
python tools/build_reloc.py   # 실험1  + verify_reloc.py
python tools/build_grow.py    # 실험2  + 인라인 검증
```

디렉터리 레코드 필드 (ISO9660, both-endian 주의):

| 오프셋 | 내용 |
|---|---|
| +2 / +6 | extent LBA (LE / BE) |
| +10 / +14 | 데이터 길이 (LE / BE) |
| +32 | 이름 길이, +33 이름 |

## 남은 제약

1. **확장 상한 미측정.** 256글리프 추가까지만 확인했다. 폰트 적재 버퍼에 상한이 있을 수 있으므로
   실제 필요치(1,000~1,500글리프)로 키울 때 다시 확인해야 한다.
2. **디스크 여유가 150섹터(300KB)뿐.** 확장된 ASCGSCG가 54섹터를 써서 96섹터 남는다.
   ASC16CG까지 크게 키우려면 부족할 수 있다. 검토 후보:
   - 내용 동일 중복 파일 회수 (San11에서 4,145개 발견 전례)
   - Track 01 자체를 연장 (bin 크기 변경 → cue 타이밍 영향 확인 필요)
3. `/ASC16CG`는 **디렉터리 엔트리가 2벌**(lba 4108·3462)이다. 재배치·확장 시 양쪽 처리 규칙을
   먼저 정해야 한다(둘 다 옮길지, 하나로 합칠지).
